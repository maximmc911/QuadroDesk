# Описание кода Electron

## Назначение
Данный скрипт является точкой входа для приложения Electron. Он создаёт окно браузера и загружает в него локальное веб-приложение, работающее на `http://localhost:5173` (например, Vite или другой dev-сервер).

## Основные компоненты

### Импорты
- `app`, `BrowserWindow`, `Menu` из модуля `electron` — управление жизненным циклом приложения, создание окон и управление системным меню.
- `path` — модуль Node.js для работы с путями (в текущем коде не используется, но импортирован).

### Функция `createWindow()`
Создаёт главное окно приложения с параметрами:
- **Ширина**: 1920 пикселей
- **Высота**: 800 пикселей

**Закомментированные опции:**
- `fullscreen: true` — полноэкранный режим
- `frame: true` — стандартная рамка окна
- Исходный размер окна `1200x800` (закомментирован)

**Загрузка содержимого:**
- `win.loadURL("http://localhost:5173")` — загружает URL dev-сервера.
- Закомментирован вариант `win.loadFile("dist/index.html")` — для загрузки собранной production-версии.

### Жизненный цикл
- `app.whenReady().then(...)` — после инициализации Electron:
  1. Удаляется системное меню приложения (`Menu.setApplicationMenu(null)`).
  2. Вызывается `createWindow()`.

## Закомментированный блок
Содержит альтернативный вариант кода с использованием `require()` вместо `import`, а также загрузку файла `dist/index.html`. Этот блок, вероятно, оставлен для production-сборки.

## Особенности
- **Режим разработки**: приложение ожидает запущенный dev-сервер на порту 5173.
- **Отсутствует обработка закрытия окна** и событий для macOS (например, повторное создание окна при активации).
- **Отключено системное меню** — приложение будет без стандартного меню (Файл, Правка и т.д.).

## Рекомендации
1. Для production-сборки заменить `loadURL` на `loadFile` и указать правильный путь к собранным файлам.
2. Добавить обработку события `window-all-closed` (для выхода из приложения на Windows/Linux).
3. На macOS добавить логику для восстановления окна при клике на иконку в доке.
